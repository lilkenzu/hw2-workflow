# Курсы валют ЦБ РФ: аудит, риски, автоматизация

ДЗ №2 · вариант **B1** («Курсы валют ЦБ: сбор, проверка, расхождения») ·
агенты + workflow, курс «Занятие 2».

Сбор реальных данных ЦБ РФ (USD/EUR/CNY, без ключей и регистрации), поиск
пропусков/аномалий/ошибок парсинга, оценка бизнес-риска, воспроизводимый
workflow одной командой. Три зоны ответственности — аудит данных сделан
напрямую, оценка риска и проектирование процесса — двумя настоящими
параллельными субагентами.

## Как запустить workflow

Зависимости — только Python 3.9+ стандартной библиотеки, ничего ставить не нужно.

```bash
cd workflow
chmod +x run_report.sh

# произвольный период
./run_report.sh 29.07.2026 28.08.2026

# регулярный прогон — прошлый календарный месяц
./run_report.sh --last-month
```

Результат — `report_<даты>.md` в папке `workflow/`. Пример реального вывода
уже лежит там же: [`workflow/report_2026-07-29_2026-08-28.md`](workflow/report_2026-07-29_2026-08-28.md).

**Коды возврата** (готовы для cron): `0` — находок нет, `2` — есть находки,
требующие внимания, иначе — сбой пайплайна (сеть/парсинг).

```bash
# пример: ежемесячно, 1-го числа в 09:00
0 9 1 * * /path/to/workflow/run_report.sh --last-month >> logs/cron.log 2>&1
```

## Агенты и workflow (как требует ДЗ №2)

- **Агенты:** оценка риска и проектирование процесса выполнены двумя
  настоящими параллельными субагентами (`Agent` tool), не эмуляцией одной
  моделью — подробности и обоснование в `sessions/session-1.md`.
- **Workflow — обязательный пункт:** `workflow/run_report.sh`, проверен
  живым прогоном на реальных данных ЦБ; в процессе проверки найден и
  исправлен реальный баг (код возврата терялся из-за отсутствующего `exit`).
- **Честность:** оба найденных в процессе бага (в workflow-скрипте и в
  вёрстке презентации) задокументированы как есть, не скрыты —
  `sessions/STATE.md`.
